how it runs

01
collect
Each source is queried in parallel through its own API — nothing routed through a third party.
02
synthesize
Raw items get sorted into what needs a response, what's already resolved, and what's worth knowing.
03
render
Laid out for e-ink — high contrast, no color dependence, sized to the device.
04
deliver
Lands in a dated folder on the reMarkable before the day starts. No app to open first.

self-hosted, on your terms

Runs in Docker on your own hardware. Every token lives in a file you control, not a vendor's database. The scheduler, the config, and the run history are all local — nothing phones home except the APIs it's built to call.

A small dashboard runs alongside it on your network: last run status, per-source auth health, and a manual trigger, for the mornings you want it early.

Source available on GitHub. Built for a home server; runs anywhere Docker runs.
